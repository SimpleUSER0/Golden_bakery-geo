# GOLDEN CRUST — ქართული დემო საიტი

სრულად ქართული, ადაპტირებადი, ერთგვერდიანი საცხობის დემო, შექმნილი HTML-ით, CSS-ითა და ჩვეულებრივი JavaScript-ით. არ სჭირდება ჩარჩო, ინსტალაცია, აგება ან სერვერული ნაწილი.

## პროექტის სტატუსი

**გამოგონილი პორტფოლიო პროექტი — რეალურ საცხობს არ წარმოადგენს.**

პროდუქტები, ფასები, შეფასებები, მისამართი, სამუშაო საათები და საკონტაქტო მონაცემები სადემონსტრაციოა. გამოყენებული ფოტოები საილუსტრაციოა. წყაროები და ლიცენზიები მოცემულია `CREDITS.md`-ში.

ყველა ხილული ტექსტი, ფორმის შეცდომა, შეტყობინება და ფოტოს აღწერა ქართულადაა. ბრენდის სახელი რჩება GOLDEN CRUST. ქართული ტექსტისთვის გამოიყენება ადგილობრივი Noto Serif Georgian და Noto Sans Georgian; ბრენდისთვის — Fraunces. გარე შრიფტები და ფოტოები გვერდის მუშაობისას არ იტვირთება.

## ლოკალურად გახსნა

1. ამოარქივე ZIP.
2. გახსენი `index.html` თანამედროვე ბრაუზერში.
3. `css`, `js` და `assets` საქაღალდეები დატოვე მის გვერდით.

სურვილის შემთხვევაში, პროექტის საქაღალდიდან გაუშვი `python -m http.server 8000` და გახსენი `http://localhost:8000`. Python საიტის მუშაობისთვის საჭირო არ არის.

## GitHub Pages-ზე გამოქვეყნება

1. შექმენი ახალი საჯარო საცავი, მაგალითად `golden-crust`.
2. აირჩიე **Add file → Upload files** და ატვირთე ამოარქივებული **შიგთავსი**. თავად ZIP ან მისი გარე საქაღალდე არ ატვირთო. `index.html` უნდა იყოს საცავის მთავარ დონეზე.
3. შეინახე ფაილები `main` განშტოებაში.
4. გახსენი **Settings → Pages**.
5. აირჩიე **Deploy from a branch**, შემდეგ **main**, **/(root)** და **Save**.
6. დაელოდე გამოქვეყნებას და გახსენი ამავე გვერდზე ნაჩვენები ბმული.

ბმულის ჩვეულებრივი ფორმატია `https://YOUR-USERNAME.github.io/golden-crust/`. ყველა ფაილის მისამართი ფარდობითია და საცავის სახელის შეცვლასაც უძლებს. `.nojekyll` გამორიცხავს დამატებითი აგების საჭიროებას.

ოფიციალური ინსტრუქცია: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## ფუნქციები

- ფიქსირებული ზედა მენიუ, მობილური მენიუ, რბილი გადასვლები და კლავიატურის ფოკუსი.
- პროდუქციის ფილტრები და კატეგორიების ბარათები.
- წინასწარი შეკვეთის ფორმა — პროდუქტის ღილაკი ავტომატურად ირჩევს შესაბამის პროდუქტს.
- ტორტის ცალკე დემო ფორმა: სახელი, ტელეფონი, ტიპი, ულუფები, თარიღი და დამატებითი ინფორმაცია.
- ქართულად ნაჩვენები ვალიდაცია: სავალდებულო ველები, ტელეფონის ციფრები, რეალური კალენდარული თარიღი და რაოდენობა.
- თარიღის შეყვანის ფორმატია `წწწწ-თთ-დდ`, მაგალითად `2026-10-10`. ბრაუზერის ენის მიუხედავად, შეცდომები ქართულად ჩანს.
- გალერეა გადიდებით, ისრებით, კლავიატურით, თითით გადაფურცვლით და დახურვით.
- ვოთსაპის ღილაკი ხსნის ადგილობრივ დემო ფორმას ქართულად შევსებული შეტყობინებით.
- ტელეფონის, ელფოსტისა და ინსტაგრამის ღილაკები ხსნის ქართულ დემო განმარტებას.
- სურათები იტვირთება საჭიროებისას; მთავარი ფოტო მობილურისთვის ცალკეა ოპტიმიზებული.
- შემცირებული მოძრაობის სისტემური პარამეტრი გათვალისწინებულია.

## ფორმები და მონაცემები

ფორმები რეალურ შეკვეთას არ ქმნის, არ აგზავნის შეტყობინებას და არ ინახავს ინფორმაციას. გამოიყენე საცდელი მონაცემები. გაგზავნისა და დახურვის შემდეგ ველები იწმინდება.

დადასტურება: **„გმადლობთ! ეს არის დემო შეკვეთის ფორმა.“**

არ გამოიყენება ქსელური გაგზავნა, ანალიტიკა, ქუქიები ან ბრაუზერის საცავი. რუკის ღილაკი ხსნის მხოლოდ თბილისის რუკას — გამოგონილი მისამართის რეალურ წერტილს არ აღნიშნავს.

## ფაილები და ცვლილებები

- `index.html` — ტექსტები, ფასები, საათები, სექციები, ფორმები და ქართული მეტამონაცემები.
- `css/style.css` — ფერები, განლაგება, შრიფტები და ანიმაციები.
- `js/script.js` — მენიუ, ფილტრები, გალერეა, ფორმები და ქართული შეტყობინებები.
- `assets/images/` — ადგილობრივი ოპტიმიზებული ფოტოები.
- `assets/fonts/` — ადგილობრივი შრიფტები და ლიცენზიები.
- `CREDITS.md` — გამოყენებული მასალების წყაროები.
- `QA.md` — შემოწმების ანგარიში.

პროდუქტის გადარქმევისას შეცვალე მისი `data-preorder` მნიშვნელობა და ფორმის შესაბამისი არჩევანიც. დღის მენიუ იცვლება ხელით, `#todays-bake` სექციაში. რეალური ბიზნესისთვის საჭიროა დადასტურებული მონაცემები და შეკვეთების მიმღები ცალკე სერვისი.

საიტს აქვს ქართული სათაური და აღწერა, გაზიარების მეტამონაცემები, `lang="ka"`, `og:locale="ka_GE"` და ბრენდის ხატულა. დემოსთვის დატოვებულია `noindex, nofollow`; ეს გვერდს კერძოს არ ხდის.
